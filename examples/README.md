# Examples

This directory contains canonical examples
used to validate the stability of the Cultural Strategy Lab.

All examples are designed to be:
- API-free
- Copy-and-paste ready
- Usable directly in Claude Code or Claude Desktop

Each example is structured to:
- Trigger a specific cultural archetype
- Validate archetype routing accuracy
- Prevent feature-level or market-level drift

### How to Use

1. Paste ACTIVATE.md into Claude
2. Open any example file
3. Copy the prompt under “How to Run (No API)”
4. Compare the output with the Expected Archetype and signals

### When to Run Examples

Run these examples after:
- Modifying SKILL.md
- Adding new context documents
- Changing archetype definitions

If outputs deviate from expectations, review:
- SKILL.md
- context_documents/archetype_router.md
- context_documents/archetype_tests.md
