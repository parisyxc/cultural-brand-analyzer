# CONTRIBUTING.md

**Cultural Strategy Lab**

---

## Why Contribute

Cultural Strategy Lab is not a prompt collection.
It is a **cultural reasoning skill**.

Contributions are welcome only if they **strengthen the cultural explanatory power** of the system.

The goal of this project is not growth, but clarity.

---

## What You Can Contribute

We welcome contributions in the following areas:

### 1. Canonical Cultural Cases (Highly Encouraged)

You may contribute new cultural cases that:

* Represent a brand, technology, product, or phenomenon
* Clearly map to one primary cultural archetype
* Demonstrate cultural tension → ideological vacuum → cultural solution
* Extend the systems explanatory range

Examples:

* Emerging AI-native brands
* Creator economy platforms
* New cultural movements or identity shifts
* Non-Western or region-specific cases

All cases must follow the case format used in `context_documents/`.

---

### 2. Archetype Boundary Tests

You may contribute edge cases that:

* Challenge existing archetype boundaries
* Sit between two archetypes
* Reveal limitations or ambiguities in the framework

These contributions should focus on **analysis**, not conclusions.

---

### 3. Methodological Clarifications

You may propose clarifications that:

* Explain when the framework should not be used
* Identify common misinterpretations
* Improve conceptual precision

Clarifications should not rewrite the core theory.

---

## What You Should NOT Contribute

Please do not submit:

* Marketing strategies or growth advice
* Prompt hacks or optimization tricks
* Feature comparisons or product reviews
* Trend forecasts or speculative analysis
* Tactical or execution-oriented content

These will be rejected without review.

---

## Contribution Format

### For New Cases

Submit a Markdown file under:

```
context_documents/
```

File naming convention:

```
case_name.md
```

Each case must include:

* Cultural tension
* Ideological vacuum
* Cultural myth or symbolic system
* Archetype justification

---

## Review Philosophy

This project follows a **curated contribution model**.

* Not all contributions will be merged
* Quality and theoretical consistency are prioritized
* Rejections may not receive detailed feedback

This is intentional.

---

## Governance

The project maintainer acts as:

* Curator of the framework
* Guardian of theoretical integrity
* Final arbiter of merges

This ensures long-term coherence.

---

## Final Note

Cultural Strategy Lab treats culture as infrastructure.

If your contribution helps explain the world more clearly,
it is welcome.

If it simplifies, instrumentalizes, or commodifies the framework,
it is not.

---

Thank you for contributing thoughtfully and rigorously.
